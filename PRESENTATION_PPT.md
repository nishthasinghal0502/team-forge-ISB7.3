### Slide 6: Deep-Dive: Autonomous Search & Anti-Hallucination Grounding

- **Slide Type**: Technical Deep-Dive / Code & Logic
- **Visual Layout**: Two-column layout: Left shows the CrewAI Tool-Calling mechanism; Right shows the Honest Grounding Invariant and Snippet Budgeting logic.
- **Headline**: Zero-Hallucination Engineering

#### 1. Autonomous CrewAI Tool-Calling
- `MarketResearchAgent` autonomously orchestrates 4 specialized search tools:
  - `search_competitors(query)`
  - `search_customer_demand(query)`
  - `search_market_size(query)`
  - `search_industry_news(query)`
- **Selective Autonomy**: B2C/health ideas trigger consumer sentiment searches; enterprise/deep-tech concepts automatically bypass consumer forums to eliminate noise.

#### 2. Disciplined Snippet Budgeting (1,500 chars/source)
- Prevents premature context truncation.
- Guarantees competitor products mentioned deep in articles (e.g., Medisafe, Propeller Health) are fully ingested by downstream agents.

#### 3. Honest Grounding Invariant
- If web searches return 0 citations for a metric, the system **never synthesizes numbers**.
- Displays an explicit amber disclaimer:
  > *"Notice: Zero direct web sources were found for Customer Demand. Personas shown below are theoretical profiles derived from problem analysis, not empirical user surveys."*

- **Speaker Script**:
  > *"How do we guarantee that market size numbers and competitors aren't hallucinated? First, through disciplined snippet budgeting: every source is allocated up to 1,500 characters so real competitor names aren't cut off. Second, through our Honest Grounding Invariant: if search engines return zero citations for a category, VYIBE transparently tells the founder rather than making up fictional data."*

- **Headline**: Production-Grade Reliability at $0 Operating Cost

#### 1. Zero-Friction Authentication
- **Google OAuth 2.0**: One-tap sign-in issuing 7-day signed HMAC-SHA256 JWTs.
- Automatic founder profile hydration and report history sync.

#### 2. Native Background Job Queue
- **No Redis / Celery Overhead**: Leverages FastAPI native `BackgroundTasks` running in Python's internal event loop.
- Client immediately receives `HTTP 202 Accepted` with `job_id`.

#### 3. Automated Executive Email Delivery
- Compiles the completed dossier into responsive HTML email reports.
- Dispatched via TLS SMTP (`smtp.gmail.com:587`) or Resend API.

#### 4. Embedded ACID Persistence
- Zero-config SQLite database (`team_forge.db`) storing `users` and `validation_jobs`.
- Real-time job polling (`GET /api/jobs/{id}`) and "My Reports" library drawer.

- **Speaker Script**:
  > *"Scalability does not require bloated infrastructure. We engineered an entire production-grade async pipeline at zero dollar cost.
